# Défi de refactoring — Galactic Freight

Une compagnie de transport interstellaire a grandi trop vite. Le programme fonctionne, mais son code est devenu difficile à comprendre et à modifier.

## Mission

Refactorez le projet sans modifier son comportement observable. Vous pouvez renommer, extraire, déplacer ou supprimer du code, modifier la visibilité, créer des classes et introduire des exceptions ou des objets paramètres lorsque cela est pertinent.

Contraintes :

- le projet doit compiler après chaque petite étape;
- consignez vos refactorings dans `REFACTORING.md`;
- faites de petits commits portant un nom clair.

## Livrable suggéré

Dans `REFACTORING.md`, documentez au moins dix refactorings avec : le problème observé, la transformation appliquée et son effet sur la lisibilité ou la maintenabilité.

> Attention : un refactoring modifie la structure, pas les fonctionnalités.
